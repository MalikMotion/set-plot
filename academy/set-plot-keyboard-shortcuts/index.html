Set Plot keyboard shortcuts: the complete cheat sheet

By Malik Motion5 min readUpdated 11 November 2026

Quick answer

Press ? in Set Plot to see every shortcut. The essentials: Z fit, Shift + A search and add, 1–6 left toolbar, Shift + 1–9 right toolbar, B beams, S snap, M modifier, [ ] rotate, ⌘/Ctrl + D duplicate, X delete. Click Customize in the shortcuts window to change any of them.

Set Plot is quick with a mouse, and much quicker with the keyboard. These are the defaults; if you change one in Customize, the tooltips and this window update to match.

Customizing shortcuts

Open the shortcuts window with ? and click Customize. Click a shortcut and press the new key or combination; if the key is already in use it moves to the new action. Reset all takes you back to the defaults. Your shortcuts are saved in the browser.

Step by step

  1. Open the listPress ? to open the shortcuts window.
  2. CustomizeClick Customize, then click the shortcut you want to change.
  3. Press the new keysPress the new key or combination.
  4. Reset if neededUse Reset all to go back to the defaults.

Tips and tricks

  • Every toolbar button shows its shortcut in the tooltip.
  • On a Mac, ⌘ is Command and ⌥ is Option; on Windows use Ctrl and Alt.
  • Number keys work by position, so Shift + 1 works on every keyboard layout.

Frequently asked questions

How do I see all shortcuts in Set Plot?

Press ? or click the ? button in the bottom right corner.

Can I change Set Plot shortcuts?

Yes. Open the shortcuts window and click Customize.
